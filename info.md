# Environment Canada Weather Alerts

Detailed weather alerts from Environment Canada for Home Assistant.

Features:

- UI-based setup from the Home Assistant integrations page
- Paste a warning URL or an Environment Canada zone code
- Multiple regions supported
- Markdown-ready sensors for dashboards and automations
- Copy-paste examples in the `examples/` folder

Sensors created for each region:

- Alert Count
- Alert Summary
- Alert Detail
- Max Alert Level

See the repository README for setup and publishing details.
