# Examples

These examples are ready to paste into Home Assistant with one change:

- Replace `sensor.my_region_*` with the entity IDs created by your config entry.

If you left the friendly name blank during setup, Home Assistant will build entity IDs from the official Environment Canada region name.

Files included here:

- `lovelace/alert_summary_card.yaml`
- `lovelace/alert_detail_card.yaml`
- `lovelace/alert_overview_stack.yaml`
- `automations/notify_on_new_alert.yaml`
